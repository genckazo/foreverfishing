# ForeverFishing

WoW Forever fishing assistant addon: live Auction House prices for fish, "where to fish right now" recommendations, and a session coach.

## Download and install

1. Click **Code > Download ZIP** on this page (or clone: `git clone https://github.com/genckazo/foreverfishing.git`).
2. Extract and drop the `ForeverFishing` folder into your client's `Interface/AddOns/`.
3. In game, replace the placeholder `## Interface:` in `ForeverFishing.toc` with your `/dump GetBuildInfo()` value (see `ForeverFishing/COMPAT.md`), then `/reload`.
4. Type `/ff panel`. Full docs in `ForeverFishing/README.md`.
